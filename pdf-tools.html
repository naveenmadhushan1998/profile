Merge PDF

Combine multiple PDF files into one, in the order you choose.

Split PDF

Break a PDF into individual pages, or extract custom page ranges — delivered as a ZIP.

Each range becomes its own PDF in the ZIP.

Compress PDF

Reduce file size by re-rendering pages at a chosen quality. Best for scanned or image-heavy PDFs — text becomes part of the page image.

Organize PDF

Drag thumbnails to reorder, tap × to delete, or add pages from another PDF.

0 pages

Remove / Extract Pages

Keep only the pages you need, or delete specific ones.

Repair PDF

Attempts to rebuild a damaged or corrupted PDF's internal structure so it opens correctly again.

PDF to Word

Extracts the text from your PDF into an editable .docx file. Complex layouts, tables, and images aren't preserved.

PDF to Excel

Extracts text positioned into rows and columns — one sheet per page. Works best on simple tables.

PDF to PowerPoint

Each PDF page becomes a full-slide image in a new .pptx file — visual layout is preserved exactly.

PDF to JPG

Turn every page into a JPG image. A single page downloads directly; multiple pages come as a ZIP.

Word / Excel / PowerPoint to PDF

Upload a .docx, .xlsx, or .pptx file — the type is auto-detected. PowerPoint conversion extracts slide text only (visual design isn't reproduced).

JPG to PDF

Combine one or more images into a single PDF, one image per page.

HTML to PDF

Paste raw HTML to convert directly. Fetching a live URL only works if that site allows cross-origin access from the browser — if it fails, use your browser's Print → Save as PDF instead.

Watermark

Stamp a diagonal text watermark across every page.

Rotate PDF

Rotate all pages, or just a chosen range, by 90° increments.
